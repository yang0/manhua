# 漫画风格与分镜机制资料包

- 漫画类型：120 种
- 分镜机制：80 种
- [图库浏览页](gallery.html)：按四宫格分组搜索、切换并浏览全部风格与分镜演示图，点击可查看大图
- `comic-style-previews/`：30 张风格演示图（每张覆盖连续 4 个编号，01–120）
- `storyboard-previews/`：20 张分镜演示图（每张覆盖连续 4 个编号，01–80）
- `data-and-prompts/`：原始 Markdown、JSON、CSV 与提示词库
- GPT Image 2.5 风格卡：120 条
- 格式：Markdown / JSON / CSV / WebP

## 最重要的使用原则
不要只写“港漫”“水墨漫画”“孟菲斯漫画”等标签。
优先复制 `data-and-prompts/漫画类型_120种_GPT_Image_2.5风格特征与提示词.md`
中对应类型的“可直接复制的核心提示词”，再追加故事、人物、对白、分镜机制和画幅。

推荐公式：
**故事 + 漫画视觉体系 + 分镜机制 + 画幅 + 对白要求**

这样可以让线条、人物、色彩、渲染、光影、材质和版式一起锁定风格，而不是只做表面滤镜变化。

## 项目 Skill

`.codex/skills/comic-page-generator/` 支持简短输入：`风格 36，分镜 79，主题：雨夜山寺重逢`。
它会从本项目数据中精确取出对应风格与分镜提示词，再生成一张完整的漫画页面；若只需要提示词，也可直接说明“只要提示词”。
